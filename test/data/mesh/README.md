Most mesh files originate from the MFEM repository, see
https://github.com/mfem/mfem/tree/master/data.

`cpw3d-surface-nc.msh` is a first-order, two-layer extrusion generated by
`examples/cpw3d_surface/mesh/mesh_cpw3d.jl` with:

```text
w_trace=20, w_gap=12, w_ground=40
h_substrate=40, h_vacuum=40
lc_fine=2.5, lc_far=20
extrude_length=20, extrude_nz=2
```

It exercises boundary-edge extraction after conversion to a nonconforming
parallel mesh.
