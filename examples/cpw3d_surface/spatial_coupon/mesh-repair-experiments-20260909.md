# Mesh repair and height-grading experiments (2026-09-09)

These are isolated experiments, not production mesher defaults. Existing meshes,
libraries and running response-generation jobs are unchanged.

Remote root: `/data/home/simlap/coupon_mesh_experiments_20260909`.
The original ten-edge p5 plan was exported from the actual thin mesh by
`audit_coupon_mesh.cpp`, not regenerated by CAD/Gmsh. Reconstructing the baseline
reproduced 2,902,680 thin prisms and maximum MFEM kappa 5606.45.

## Candidate sequence

1. **repair**: flip interior diagonals only for convex pairs with matching material and
   interface-slot labels. No original vertex is moved. Sixteen flips improved some
   triangles but did not change the minimum plan angle or maximum prism condition number.
2. **repair-relocate** (plan-only screening): constrained tangential row relocation with a
   strict edge-growth bound. Eighty moves did not improve the global minimum angle.
3. **aligned**: add tangential stations to adjacent artificial rows in skinny fans, then
   flip interior diagonals. Adds 40 vertices / 80 triangles to the 80,630-triangle plan.
   All old coordinates and the external/material boundary geometry are preserved.
   Thin volume elements increase by 0.099%; maximum kappa falls 5606.45 -> 4442.02.
   The count above kappa=1000 increases 260 -> 328, so this is not an unqualified quality
   improvement and no speedup is assumed.
4. **aligned-smooth**: alignment plus more permissive, phase/slot-preserving tangential
   relocation of row/interior nodes (up to 1.5x local incident-edge length bound), followed
   by flips. Plan-only screening gives minimum angle 0.385 degrees and predicts maximum
   thin/fabricated prism kappa 2239.71/1853.84. Tangential resolution can change locally;
   accuracy must be checked. Physical boundary vertices and row-normal coordinates stay
   fixed, and candidates do not introduce a closer-than-2nm physical-edge node.
5. **aligned-coarsen-z**: conservative merging of far vertical intervals only, outside
   0.2 um of process planes, with merged intervals <=0.65 um. This is NOT in-plane
   coarsening with height. Thin elements fall to 2,582,720; max kappa stays 4442.02,
   but the count above 1000 rises to 424.
6. **nc**: stronger spatially graded height experiment using an aligned-smoothed plan.
   Start from a seed with fine vertical intervals removed near process planes, then
   restore near-edge height resolution through native MFEM nonconforming Z refinement.
   The requested height is clamped between 2 nm and 500 nm, using distance to physical
   edges and process planes, with NC level difference limited to two. Binary subdivisions
   may produce finer-than-2nm cells. There are no unmatched nonconforming slab interfaces:
   MFEM owns the refinement hierarchy and constraints. This still retains one XY plan;
   coarsening the XY triangulation with height needs a separate transition construction.

## Checks

- `test_plan_repair.jl`: convex flip, material-boundary exclusion, unchanged old nodes,
  preserved external boundary edges, manifold adjacency, and a synthetic skinny-fan
  alignment case (14 assertions passed on Julia 1.10.4).
- Native MFEM height-refinement smoke: one prism refines to 25 graded-height prisms,
  writes/reloads a native NC mesh, with positive audited Jacobians.
- Every candidate is written/reloaded by Gmsh, with positive minSJ and matching face
  topology checked; candidates are subsequently audited using the same MFEM kappa metric.
- Mesh generation is limited to 900 seconds per case, audit to 180 seconds, and NC
  height refinement to 600 seconds with a 5-million-element budget.
